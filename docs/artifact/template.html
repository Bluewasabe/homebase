What the bake-off found in the lab

My read. Two ideas survived contact: H3's "alerts, then eight links" for the phone and H2's function rows for the desk. Homepage can do both from one services.yaml with two thin settings files. On the Glance side, G2 proved the platform can match Homepage on ops data at the cost of owning Go templates; G3 is the better Glance pick because its Home is calm and its Games page is the best game-server view of the six. If you want one answer: H2 for the desk, with H3's Fleet / Alerts / Top-8 block lifted to the top. It's your call.

Decisions and items for you

  • Pick a variant (or a combination). Phase 2 promotes it to http://hub and stops the other five.
  • UniFi read-only local user on the UDM Pro, for the network widget.
  • Discord channel + webhook URL for alerts. Goes in hub's .env, then ops/kuma-sync.py wires it to every monitor.
  • DHCP reservation for hub at 192.168.1.141.
  • File Browser port map on Server-Rig (8085→85 should be 8085→80).
  • Server-Rig .wslconfig memory cap before reviving Hytale or TubeIntel.
